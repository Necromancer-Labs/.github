# Code of Conduct

## Standards

This is a security research community. We expect:

- Technical honesty
- Constructive criticism
- Respect for differing experience levels and perspectives
- Focus on the work, not the person

We do not tolerate:

- Harassment or personal attacks
- Publishing others' private information
- Using project resources to attack systems without authorization

## Scope

This applies to all Necromancer Labs repositories, issues, pull requests, and related communication channels.

## Enforcement

Maintainers will review and respond appropriately. Actions may include warnings, temporary bans, or permanent removal from the community.

## Attribution

This is a simplified code of conduct for a technical community. For questions about interpretation, reach out to maintainers.
