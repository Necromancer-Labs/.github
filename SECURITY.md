# Security Policy

Our tools are primarily intended for local testing and research. For most issues, opening a GitHub issue is fine.

## Severe Vulnerabilities

If you believe you've found a critical vulnerability that could impact users in a significant way, please email **business[at]necromancerlabs.com** instead of opening a public issue.

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We'll acknowledge within 48 hours and work with you on a disclosure timeline.

## Everything Else

For general bugs, minor issues, or questions — just open a GitHub issue on the relevant repository.
